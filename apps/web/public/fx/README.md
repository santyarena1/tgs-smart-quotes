# Video de fondo del tema BeGamer (opcional)

El tema **BeGamer** dibuja solo un "reel" de PCs gamer (torres con ventiladores RGB, láseres, glitches y un HUD de grabación).

Si querés usar un video real de showcase de PCs, copiá acá un archivo llamado:

    gamer-showcase.mp4

Se usa de fondo (sin sonido, en bucle) y el tema le suma encima láseres, HUD y glitches. Si el archivo no existe, se usa el reel dibujado.

Recomendaciones: H.264, 1280x720 o 1920x1080, menos de 15 MB, y que sea un video que tengas derecho a usar.
